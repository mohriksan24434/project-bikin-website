## 🚀 Cara Menjalankan Website

1. **Buka Langsung di Peramban (Browser):**
   * Klik dua kali (double click) pada file `index.html`.
   * File akan otomatis terbuka di browser pilihan Anda (Google Chrome, Safari, Firefox, Microsoft Edge, dll.).
   
2. **Atau Menggunakan Local Server (Opsional):**
   Jika menggunakan terminal:
   ```bash
   cd blog-pribadi-cbt26
   python3 -m http.server 8000
   ```
   Kemudian buka peramban di `http://localhost:8000`.

## 📸 Format Pengumpulan untuk CBT26
1. **Folder / File ZIP:** File `blog-pribadi-cbt26.zip` siap dikumpulkan.
2. **Screenshot:** Ambil tangkapan layar (screenshot) halaman Home, About, dan Contact saat dibuka di browser.
   * Di Mac: Tekan `Cmd + Shift + 4` lalu seret area tampilan browser.
   * Di Windows: Tekan `Win + Shift + S`.
